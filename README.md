# Broomball · 金色球场

默认体验入口是根目录 `index.html`，用 Chrome 或 Edge 打开即可游玩。Three.js 已固定保存在 `vendor/`，无需联网加载。请保留 `index.html`、`game-environment.js`、`game-houses.js` 和 `vendor/` 的相对位置。

本轮体验与地图升级在浏览器版实现。Godot 版入口为 `project.godot`，使用 Godot 4.5.1；它保留此前的核心玩法，浏览器新增的训练、传球、模式、四学院与本轮手感优化尚未同步到原生版。

## 从这里开始

- **引导训练**：无计时、无敌方干扰，实际完成飞行、升降、拾球、射门得分与施法后进入标准赛；射偏可重新拾球继续练习。
- **标准赛**：3 分钟，110 秒后出现金色飞贼，对手找球手在 130 秒后才参与争夺。
- **挑战赛**：2 分 30 秒，更快的对手；78 秒释放飞贼，93 秒后双方争夺。

主菜单可选择格兰芬多、斯莱特林、拉文克劳、赫奇帕奇，以及另一个学院作为对手。队服、围巾、比分和结算名称随选择同步；看台展示四院徽章旗帜。学院选择会保存，巫师技能可与学院外观自由搭配。

球场设有己方接应手和守门员。持球时按 T 传给 30 米内的接应手；队友持球时按 T 要球，距离超过 38 米时队友会先靠近。收到回传提示后松开移动键或按 X 减速接球，球保持较慢的可见飞行速度。雷达中的暖色点为队友。比赛结算展示射门、全队进球、抢断、传球次数及当前模式的本机最高分。

## 操作

| 操作 | 按键 |
| --- | --- |
| 按镜头方向移动 / 后退 | W A S D |
| 上升 / 下降 | Space 或 E / Q 或 Ctrl |
| 加速 / 急停 | Shift / X |
| 射门 | F 或鼠标左键 |
| 传给接应队友 / 向持球队友要球 | T |
| 释放当前咒语 | R 或鼠标右键 |
| 切换哈利、赫敏、罗恩 | 1 / 2 / 3 |
| 第一、第三人称切换 | V |
| 暂停 / 继续 | Esc |
| 完整玩法说明（浏览器版） | H |
| 键盘转向 / 镜头俯仰 | ← → / I K |
| 切换飞贼追踪（出现后） | Tab |

松开移动键会自动制动。训练与标准赛巡航速度为 22，加速速度为 36；挑战赛为 28 / 48。冲刺消耗体力，停止冲刺后恢复；X 急停优先于加速。键鼠转向采用短时平滑过渡，倒计时也能转动视角。鼠标捕获失败时仍可用键盘转向和瞄准。暂停菜单可调灵敏度，或勾选“减少镜头动态”关闭加速视野扩张与骑手侧倾；设置自动保存。暂停、结算和训练完成界面均可返回主菜单。

## 咒语与比赛

| 角色 | 咒语 | 实际效果 | 冷却 |
| --- | --- | --- | --- |
| 哈利 | 除你武器 · Expelliarmus | 36 米内缴械，使持球对手掉球并短暂受击 | 7 秒 |
| 赫敏 | 昏昏倒地 · Stupefy | 32 米内使对手昏迷或冻结游走球 3.2 秒；贴近昏迷持球者即可抢球 | 9 秒 |
| 罗恩 | 盔甲护身 · Protego | 4 秒内阻挡游走球与抢断，切换角色后护盾仍持续 | 12 秒 |

攻击咒语需对准目标，未锁定目标时不消耗冷却。三名角色的冷却独立计算，暂停时所有比赛计时冻结。健康持球对手需要加速接近才能抢断。

鬼飞球采用更大的亮橙球体和白色缝线，橙色跟踪圈标明位置与距离，离开视野后由边缘箭头指路。靠近自动持球，持球后隐藏找球标记并提示进攻球门。训练与标准赛接球半径为 4.2 米，开场即可拾球；拾取或接到队友传球后有 1.8 秒抢断保护。高度不合适时提示具体升降距离。

训练与标准赛玩家射门速度由 39 降为 24，传球由 34 降为 22，AI、飞贼和游走球也相应放缓。蓝色门环是进攻目标，金色门环是本方球门。进入蓝门 38 米内并将准星对准门环后提供有限瞄准辅助；球出手后沿固定方向飞行，实际穿过门环才计 10 分，背对球门的射门不会自动转弯。自由球在边界反弹，仍可追上拾取。

飞贼捕获得 150 分并结束比赛，胜负按最终总分结算。持球时目标提示优先指向进攻球门，Tab 可切换无球时的飞贼追踪。

## 地图

高地球场周围加入城堡、湖泊、树林和连续看台；装饰均位于活动边界之外。球门标牌、半场线和地面投影辅助判断方向与高度。移除场内漂浮颗粒、低空云团、空中围网和大型悬浮航标，学院旗帜集中在场外看台。静态场景按材质及阴影属性合批，动态角色、旗帜与水波保留独立动画。

## 开发验证

浏览器测试需要 Node.js 和 Playwright（可由 `NODE_PATH` 或 `PLAYWRIGHT_MODULE` 指向已安装依赖）。可用 `BROWSER_EXECUTABLE` 指定 Chromium 路径。

```text
node tests/browser-smoke.cjs
node tests/browser-smoke.cjs --file
node tests/browser-experience.cjs
node tests/browser-experience.cjs --file
node tests/browser-houses-novice.cjs --file
node tests/visual-review.cjs
godot --headless --path . --rendering-method gl_compatibility --audio-driver Dummy --log-file tests/godot-final.log --script res://tests/smoke_test.gd
```

基础浏览器测试覆盖实际键盘事件、飞行与制动、失焦、咒语命中、近距离瞄准、昏迷交互、暂停、重开和设置持久化。体验测试覆盖训练链、模式规则、真实穿门、边界、传球、体力、追踪与比赛结算，并生成实际渲染截图。学院与追球专项覆盖四院切换、队服和结算同步、球速、转向平滑、开场拾球、球标及 T 要球。最新验收见 `docs/validation/2026-11-09-houses-clarity.md`；此前记录见 `docs/validation/2026-11-06.md` 和 `docs/validation/2026-11-06-experience.md`。
