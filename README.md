# Broomball · 学院冠军赛

以足球游戏的球队配合为核心，保留扫帚飞行、四大学院和魔法门环。默认入口是根目录 `index.html`，用 Chrome 或 Edge 打开即可离线游玩。依赖、场景和六段女声解说均已随项目保存，无需联网。

本轮重设计针对浏览器版。`project.godot` 是此前的原生版本，尚未同步此次球队控制、转播镜头和声音改动。

## 新的比赛方式

- **4 对 4**：每队三名追球手、一名守门员。己方队友向两侧拉开接应，对手会逼抢和传球。
- **球队控制**：S / T 向高亮队友短传，Z 向队友前方送直塞。传球沿出手时确定的路线飞行，能被拦截；接球后自动控制接球队员。C 可手动切换到最接近球的己方追球手。
- **进攻选择**：传球预览线和球员标签标明接应目标，选择同时考虑方向、距离与对手封堵。鼠标在转播镜头中选择进攻方向，← / → 也可转向。白色短线显示当前方向。
- **射门**：按住 F 蓄力，松开出手；鼠标左键或屏幕按钮快速射门。转播镜头中朝向蓝门且在 38 米内时辅助瞄准；跟随镜头需准星对准门环。实际穿过门环得 10 分。
- **攻防转换**：B 逼近持球对手，接近后抢断；Shift 冲刺、魔法控制和守门员扑救仍可使用。进球后短暂停顿，由失球方重新开球。
- **清晰的球权信息**：默认拉远的转播镜头，显示控球状态、接应队员、传球路线、蓄力和战术雷达。V 切换跟随镜头。转播时隐藏遮挡球场的大型教学标牌。
- **固定女声**：三种咒语、开场与双方进球使用本地婷婷女声录音，不受浏览器系统语音列表影响。其余文本仅选择已知女声，不会随机切换为男声。来源与台词见 `assets/voice/VOICE.md`。

标准赛 180 秒，挑战赛 150 秒，按终场分数决胜；此次球队玩法不使用飞贼提前终结比赛。训练无计时、无对手干扰，依次完成飞行、升降、拾球、短传、射门和施法六步；实际接球和进球才推进训练。

## 操作

| 操作 | 按键 |
| --- | --- |
| 前进 / 左右横移 | W / A、D |
| 选择方向 | 转播时移动鼠标；← / → 转向 |
| 短传 / 向持球队友要球 | S 或 T |
| 直塞 | Z |
| 切换控制队员 | C |
| 蓄力射门 | 按住 F，松开射门 |
| 快速射门 | 鼠标左键 / 屏幕射门按钮 |
| 逼抢 | 按住 B |
| 冲刺 / 急停 | Shift / X |
| 上升 / 下降 | Space 或 E / Q 或 Ctrl |
| 咒语 | R 或鼠标右键 |
| 切换战术技能 | 1 / 2 / 3 |
| 转播 / 跟随镜头 | V |
| 暂停 / 说明 | Esc / H |

**没有后退按键。S 已改为短传。** 松开移动键自动制动，转向后前进可返回防守区域。传球、射门、切人也有可点击按钮。训练与标准赛巡航速度 22、冲刺 36；挑战赛为 28 / 48。冲刺消耗体力，X 急停优先于冲刺。暂停时可调整鼠标灵敏度和减少镜头动态，设置保存在本机。

## 学院和技能

可选择格兰芬多、斯莱特林、拉文克劳、赫奇帕奇和对手学院。队服、比分和结算随选择同步，学院外观与战术技能独立。

| 技能 | 效果 | 冷却 |
| --- | --- | --- |
| 1 · 除你武器 | 36 米内使持球对手掉球、短暂受击 | 7 秒 |
| 2 · 昏昏倒地 | 32 米内击晕对手 / 冻结游走球 3.2 秒 | 9 秒 |
| 3 · 盔甲护身 | 4 秒内格挡游走球与抢断 | 12 秒 |

攻击技能需朝向有效目标，无目标不消耗冷却。三种技能冷却独立，暂停冻结比赛计时。结算展示进球、射门、抢断、传球成功数、控球率和模式本机最高分。

## 开发验证

当前球队玩法验收：

```text
node tests/browser-teamplay.cjs
node tests/browser-smoke.cjs --file
node tests/browser-runtime.cjs
node tests/browser-rules.cjs --file
```

需要 Node.js、Playwright 和 Chromium。可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，通过 `BROWSER_EXECUTABLE` 指定浏览器。测试先安装统一虚拟时钟再加载游戏，覆盖真实键盘输入、接球、拦截、进球、训练全流程、暂停、低帧率及离线运行。

`tests/browser-experience.cjs`、`tests/browser-houses-novice.cjs` 是此前单人追球版的体验脚本，包含旧飞贼和回传预期；当前以球队验收脚本为准。历史验证保存在 `docs/validation/`。本轮记录见 `docs/validation/2026-11-14-teamplay-redesign.md`。
