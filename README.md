# Broomball · 金色球场

默认体验入口是根目录 `index.html`。建议在项目根目录启动本机网页服务，再用 Chrome 或 Edge 游玩，以便正常加载 GLB 模型与材质：

```text
python -m http.server 8765 --bind 127.0.0.1
```

随后打开 `http://127.0.0.1:8765/`。服务仅本机可访问。请保留整个项目目录及 `assets/`、`vendor/` 和各 JavaScript 文件的相对位置；Three.js、模型和贴图均随项目提供，游戏运行时无需从外网加载这些资源。

本轮体验与地图升级在浏览器版实现。Godot 版入口为 `project.godot`，使用 Godot 4.5.1；它保留此前的核心玩法，浏览器新增的训练、传球、模式、四学院与本轮手感优化尚未同步到原生版。

## 相比第一版的更新（update1）

本轮在原有学院友谊赛基础上，加入了 **Lux3D 生成的游戏模型、扫帚成长与队伍装备、四院专属角色，以及更容易辨认的咒语表现**。对比基准是最初克隆的第一版 `4e343ab`。

| 内容 | 第一版 | update1 |
| --- | --- | --- |
| 学院与角色 | 可选四院，技能角色固定为哈利、赫敏、罗恩 | 每院三名专属角色，共 12 名；角色、外观、技能栏和说明联动，选人按学院保存 |
| 专属咒语 | 三种技能 | 12 种不同效果；双方 AI 按角色施法，己方两名队友使用玩家未选的代表角色 |
| 咒语反馈 | 以通用命中特效为主 | 后仰松手、持续减速、侧倾偏航、蒙眼与混淆分别表现，增加状态倒计时及不同音效 |
| 扫帚与装备 | 程序生成扫帚 | 加入 Lux3D 基础扫帚，全员默认使用；商店提供实物图、装备选择、金币升级及队友配置 |
| 比赛成长 | 比分、比赛统计和最高分记录 | 新增胜平负奖金、本机装备进度，以及对手学院根据奖金自动购装和升级 |
| 金色飞贼 | 程序生成模型 | 换用 Lux3D 飞贼模型，拆分双翼制作振翅；飞行速度降低 20% |
| 鼠标兼容 | 依赖浏览器捕获鼠标进行转向 | 捕获失败时可按住左键拖动转向，保留单击射门、右键施法，并显示操作提示 |
| 施法提示 | 基础目标与冷却提示 | 飞来咒明确显示距离及持球限制；本地脚本增加内容版本标识，减少旧缓存造成的技能显示不一致 |

卢娜现使用 **呼神护卫**：银色兔形守护神护航 6 秒，保护 20 米内队友，最多挡开两次游走球，冷却 16 秒。秋张的 **飞来咒**可召回 24 米内无人持有的鬼飞球；队友持球时使用 T 要球。

当前商店有两款可用扫帚，高级扫帚模型可继续加入装备库。进度保存在当前浏览器；本轮更新作用于浏览器版。完整更新与验证说明见 [CHANGELOG.md](CHANGELOG.md)。

## 从这里开始

- **引导训练**：无计时、无敌方干扰，实际完成飞行、升降、拾球、射门得分与施法后进入标准赛；射偏可重新拾球继续练习。
- **标准赛**：3 分钟，110 秒后出现金色飞贼，对手找球手在 130 秒后才参与争夺。
- **挑战赛**：2 分 30 秒，更快的对手；78 秒释放飞贼，93 秒后双方争夺。

主菜单可选择格兰芬多、斯莱特林、拉文克劳、赫奇帕奇，以及另一个学院作为对手。队服、围巾、比分和结算名称随选择同步；看台展示四院徽章旗帜。学院选择会保存；每个学院显示自己的三名角色与专属咒语，角色选择按学院分别保存。己方两名队友使用另外两名代表角色，双方队员都会按自己的角色自动施法。

球场设有己方接应手和守门员。持球时按 T 传给 30 米内的接应手；队友持球时按 T 要球，距离超过 38 米时队友会先靠近。收到回传提示后松开移动键或按 X 减速接球，球保持较慢的可见飞行速度。雷达中的暖色点为队友。比赛结算展示射门、全队进球、抢断、传球次数及当前模式的本机最高分。

## 扫帚商店与学院奖金

主菜单点击“扫帚商店与装备”，可选择扫帚、购买后续上架的新款并升级已有装备。默认装备用户使用 Aholo Lux3D 生成的“初学者 · 木羽”，原版“经典训练扫帚”也免费保留。当前只有这两款真实可用装备，新款模型可继续加入目录。

标准赛完成后按胜 / 平 / 负获得 120 / 70 / 40 金币，挑战赛奖金为 1.5 倍；引导训练和中途退出不发奖金。扫帚各自保存升级等级，升级依次花费 100 / 200 / 300 金币，每级提升巡航和冲刺速度 3%，最高 3 级。金币、购买记录、装备和等级保存在当前浏览器的本机存档中，清除浏览器网站数据会删除这些进度。

基础扫帚原始 GLB 保留在用户下载目录，游戏使用独立简化副本（18,807 三角面、约 1.23 MiB）。后续添加模型的方法见 `assets/brooms/README.md`。新增功能验证：先启动本机网页服务，再执行 `node tests/broom-shop.cjs`，可通过 `BROOM_GAME_URL` 指定测试地址。测试使用独立浏览器上下文，不修改玩家存档。

### 队伍装备与飞贼模型

所有队员首次默认使用 Lux3D 基础扫帚。在商店下方“队伍装备”中，可为自己、接应手和守门员选择已拥有的扫帚，队友配置按学院保存。商店展示实际模型渲染图，介绍文案保留原内容，改写前由用户审核。

对手学院保存独立资金与每名队员的扫帚等级，赛后根据胜负奖金自动购置或升级装备，下场比赛使用。商店下方可查看对手余额、最近奖金与支出、各队员配置。双方装备加成都影响实际飞行速度。

金色飞贼改用用户新生成的 GLB，包含独立振翅部件；原始下载文件保留。出现时间、捕获和计分规则保持原设定。功能验证脚本：`node tests/team-equipment.cjs`（与商店测试一样，先启动本机服务；使用独立浏览器存档）。

## 操作

| 操作 | 按键 |
| --- | --- |
| 按镜头方向移动 / 后退 | W A S D |
| 上升 / 下降 | Space 或 E / Q 或 Ctrl |
| 加速 / 急停 | Shift / X |
| 射门 | F 或鼠标左键 |
| 传给接应队友 / 向持球队友要球 | T |
| 释放当前咒语 | R 或鼠标右键 |
| 切换本院三名角色 | 1 / 2 / 3 |
| 第一、第三人称切换 | V |
| 暂停 / 继续 | Esc |
| 完整玩法说明（浏览器版） | H |
| 键盘转向 / 镜头俯仰 | ← → / I K |
| 切换飞贼追踪（出现后） | Tab |

鼠标捕获成功时，移动鼠标即可转向；浏览器不支持捕获时，按住左键拖动转向，单击射门、右键施法。WASD 控制飞行。画面显示当前控制提示，Esc 暂停后仍可继续使用。鼠标兼容性测试：`node tests/mouse-controls.cjs`。

松开移动键会自动制动。训练与标准赛巡航速度为 22，加速速度为 36；挑战赛为 28 / 48。冲刺消耗体力，停止冲刺后恢复；X 急停优先于加速。键鼠转向采用短时平滑过渡，倒计时也能转动视角。鼠标捕获失败时仍可用键盘转向和瞄准。暂停菜单可调灵敏度，或勾选“减少镜头动态”关闭加速视野扩张与骑手侧倾；设置自动保存。暂停、结算和训练完成界面均可返回主菜单。

低帧率时以小步长更新物理与比赛计时，保持比赛时长、移动和技能冷却一致。单帧停顿超过 0.5 秒时自动暂停并清除按住的移动键；继续比赛后从当前位置出发。

| --- | --- | --- | --- | --- |
| 格兰芬多 | 哈利 | 除你武器 | 36 米内使目标掉球并短暂受击 | 7 秒 |
| 格兰芬多 | 赫敏 | 减震止速 | 32 米内使对手减速 3.2 秒，或冻结游走球 | 9 秒 |
| 格兰芬多 | 罗恩 | 盔甲护身 | 自身和 20 米内最近一名队友获得 4 秒护盾 | 14 秒 |
| 斯莱特林 | 德拉科 | 乌龙出洞 | 32 米内蛇形魔法使对手偏航并短暂减速 | 9 秒 |
| 斯莱特林 | 潘西 | 蒙眼咒 | 30 米内遮挡目标视野 2.8 秒，干扰移动与瞄准 | 11 秒 |
| 斯莱特林 | 布雷斯 | 混淆咒 | 30 米内使目标受假球诱导 4 秒 | 12 秒 |
| 拉文克劳 | 卢娜 | 呼神护卫 | 银色兔形守护神护航 6 秒，保护 20 米内队友，最多挡开两次游走球 | 16 秒 |
| 拉文克劳 | 秋张 | 飞来咒 | 召回 24 米内自由鬼飞球，不能夺走持有中的球或捕获飞贼 | 10 秒 |
| 拉文克劳 | 帕德玛 | 障碍重重 | 前方设置半径 6 米、持续 5 秒的敌方减速区域 | 14 秒 |
| 赫奇帕奇 | 塞德里克 | 咒立停 | 清除自身和 20 米内队友的减速、蒙眼、混淆与受击 | 12 秒 |
| 赫奇帕奇 | 汉娜 | 快快复苏 | 22 米内优先恢复受击队友；无人可帮助时恢复自身并补充 25 体力 | 14 秒 |
| 赫奇帕奇 | 厄尼 | 统统加护 | 半径 7 米、持续 6 秒的保护区，每位友方各抵挡一次攻击 | 17 秒 |

这些角色技能为学院友谊赛的游戏改编，不表示原著逐一设定。护盾能抵挡攻击咒，咒立停能解除负面效果，咒立停也能解除混淆咒的假球干扰。技能冷却不因切换本院角色而重置，所有效果在暂停时冻结、重新开赛时清除。AI 使用自身角色技能，保留额外施法间隔与瞄准要求。

攻击咒语需对准目标，未锁定目标时不消耗冷却。本院三名角色的冷却独立计算，暂停时所有比赛计时冻结。健康持球对手需要加速接近才能抢断。

鬼飞球采用更大的亮橙球体和白色缝线，橙色跟踪圈标明位置与距离，离开视野后由边缘箭头指路。靠近自动持球，持球后隐藏找球标记并提示进攻球门。训练与标准赛接球半径为 4.2 米，开场即可拾球；拾取或接到队友传球后有 1.8 秒抢断保护。高度不合适时提示具体升降距离。

训练与标准赛玩家射门速度由 39 降为 24，传球由 34 降为 22，AI、飞贼和游走球也相应放缓。蓝色门环是进攻目标，金色门环是本方球门。进入蓝门 38 米内并将准星对准门环后提供有限瞄准辅助；球出手后沿固定方向飞行，实际穿过门环才计 10 分，背对球门的射门不会自动转弯。自由球在边界反弹，仍可追上拾取。

穿门判定按门环内孔与球体外沿（含缝线）的实际尺寸计算，擦到门环的球不计分。远射会保持出手轨迹，直到越过球门平面、碰到边界或被扑救。传球和其他自由球从球场内向外穿过门环也按对应球门计分，从球门背面穿回场内不计分；门线前的接球与扑救先结算，每次穿门只计分一次。

飞贼捕获得 150 分并结束比赛，胜负按最终总分结算。持球时目标提示优先指向进攻球门，Tab 可切换无球时的飞贼追踪。

## 地图

高地球场周围加入城堡、湖泊、树林和连续看台；装饰均位于活动边界之外。球门标牌、半场线和地面投影辅助判断方向与高度。移除场内漂浮颗粒、低空云团、空中围网和大型悬浮航标，学院旗帜集中在场外看台。静态场景按材质及阴影属性合批，动态角色、旗帜与水波保留独立动画。

## 咒语动作与表现

缴械后仰松手并产生红色冲击环；减速呈现蓝色环带与较慢动作；蛇咒使扫帚侧倾并留下绿色轨迹；蒙眼显示黑色眼带和玩家视野遮挡；混淆显示紫色旋纹、张望动作和可识别的假球。

护盾使用持续蓝色随身护罩与受击涟漪；飞来咒显示杖尖牵引光带；障碍区域显示蓝色边界；解咒使对应负面效果碎裂消失；恢复使用汇聚金色光点和坐稳动作；统统加护显示固定金色穹顶与局部受击闪光。卢娜继续使用银兔呼神护卫。

目标头顶显示状态及剩余时间，命中音效按咒语区分。表现与玩法判定分离，不改变冷却、作用范围、持续时间和比赛计分。验证脚本：`node tests/spell-feedback.cjs`。
