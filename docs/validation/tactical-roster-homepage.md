# 战术转播、独立后退与十二角色首页展示

## 玩法

默认比赛视角根据当前骑手和 54 米内的两名非守门员队友计算包围区域，按屏幕比例和界面安全区调整相机距离。目标是同时看清两侧接应，而非固定锁在近处骑手后方。V 切到近景查看人物；按住 Tab 查看全场，松开恢复。

W/A/S/D 前后左右移动，S 只后退；J/T 短传，K/Z 直塞。后退为巡航速度的 65%，保持瞄准朝向，不触发冲刺和传球。K 不再控制俯仰，瞄准俯仰改用 I/O。F 蓄力射门、C 切人、B 逼抢、Shift 冲刺、X 急停、Space/Q 升降、R 施法保持独立。界面、训练提示和文档同步。

## 角色与原模型

十二角色使用可辨认的不同发型、肤色、眼睛与标志性配件：哈利眼镜与伤疤、赫敏栗色卷发、罗恩姜色头发与雀斑、德拉科铂金侧分、潘西短发、布雷斯短卷发、卢娜长金发与月亮耳饰、秋的黑色马尾、帕德玛编发、塞德里克棕色波浪发、汉娜双辫和厄尼整齐侧分。

制服、翻领、领带、围巾、披风边、手套和靴子重新制作。静态细节按材质合批，保留施法手臂、披风和围巾的动画接口。哈利继续使用上传的完整飞行 GLB，其余人物使用上传扫帚；学院主堡、塔楼、石桥、城墙和飞贼奖杯继续放在实际球场场景中，七份原文件未改写。

## 首页

首页分为设置区与三维展示区。预览直接使用比赛的 createWizard 工厂、学院换色和实际装备，模型随所选学院、人物和扫帚变化。支持拖动旋转和左右旋转按钮，异步模型加载后重新计算可见网格边界，避免把隐藏占位身体计入适配。进入比赛后停止预览渲染。测试接口暴露当前角色、可见网格和边界。
