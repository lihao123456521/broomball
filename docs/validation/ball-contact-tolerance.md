# 扩大触球与抢断判定

旧判定主要围绕右手单点、半径1.35米；从身体左侧、胸前或扫帚端接触时容易漏掉。持有中的球还要求F或高速，即使真正贴球也不一定能夺回。

本轮将所有接收、拦截、自由球拾取与近身触球共用一组区域：身体半径2.05、手部1.9、随模型转动的扫帚前端1.2/后端1.35米。覆盖视觉上的身体和扫帚，避免简单放大右手单球而导致单侧过远吸附。真正接触持球的球时，低速、不按F也能拿到；F逼抢距离由2.7放宽到3.4米，冲刺抢断为3.0米。

玩家和AI都保存前一位置，结合球的前后位置做相对扫掠，覆盖侧面飞球和高速交叉；不会因换人或人为摆位跨场扫过。对手射门保留原身体挡球范围，并叠加新触球范围与扫掠。

缩短抢断后的保护到约0.75–0.85秒，接球标准0.85/挑战0.65秒，防止刚抢到立即反复易主。落球等待0.25、扑救及发球等待0.18秒，降低视觉触球却仍被长时间忽略的情况。门将持球安全与开球保护继续保留。

## 真实验证

`tests/browser-ball-contact.cjs`的7项实际浏览器场景，以及现有`tests/browser-core-match.cjs`14项全部通过；页面错误、外部请求与失败列表均为空。

- 身体左侧/前方1.9米，以及扫帚前端z=-2.65、后端z=3.0米接触可拿球。
- 44米/秒侧飞球与球员、球相向高速交叉均可接住。
- 无F、无冲刺贴球可以夺球；F在3.3米起点80ms内可抢断。
- 8米外的自由球和持球对手都不会被吸走。
- 刚抢到后的300ms内不会被立即反抢。
- 核心传球、换控、守门员分球、射门、暂停和低位拾球仍通过。

详细结果：忽略提交的`tests/artifacts/ball-contact-browser.json`和`core-match-browser.json`。验证使用真实Chrome与游戏碰撞函数，时钟在页面加载前安装；没有用复写算法代替实际玩法。
