# 2026-11-14 球队玩法重设计验收

本轮针对根目录浏览器版，将单人追球重做为以足球游戏的控球、传切和攻防转换为核心的 4 对 4 比赛，保留学院与魔法球场。原生 Godot 版未同步。

## 已验证

以下四组共 44 项具名检查通过。

- `tests/browser-teamplay.cjs`：15 项通过，包含标准/挑战规则、S 无后退和无重复出球、方向选人、短传接球自动控制、Z 固定轨迹直塞、途中拦截、C 切人保持球权、F 蓄力与真实进球、暂停和重开清理、B 逼抢、失球方重开、训练实际短传→进球→施法、失去球权取消蓄力、守门员传球统计、六段离线音频浏览器解码。
- `tests/browser-smoke.cjs --file`：10 项通过，包含移动与制动、升降、失焦清理、三种技能、昏迷禁用拾取和射门、转播视角锁定、暂停计时、按终场分数结算、真实重开与设置保存。旧找球手断言已替换为本轮玩法。
- `tests/browser-runtime.cjs`：4 项通过，包含 60 FPS / 10 FPS / 300 ms 帧计时一致、倒计时转向、长帧自动暂停、恢复与重开时间基准。
- `tests/browser-rules.cjs --file`：15 项通过，包含远射、球门正反向、实际内孔、擦门不计分、门线前接球与扑救、守门员回传、自摆乌龙和持球穿门不计分。
- Chrome 的本地 file:// 运行中，球队测试无 JavaScript 异常、无外部网络请求。
- 6 段本地 WAV 经时长、非零峰值和 RMS 检查有效；系统女声婷婷，内容为三个咒语、开场、双方进球。模块在无系统语音合成服务的 VM 中能匹配播放本地片段，且不会退回男声。
- 实际浏览器截图检查 1440×900、1280×720、800×600。主菜单可滚动，开始/帮助可达，无横向溢出；球队 HUD、传球提示、动作栏与雷达无互相遮挡。

## 验证环境与证据

macOS 上的本机 Chrome、Playwright 和固定浏览器时钟。测试是自动化键盘与状态隔离验收，截图经过视觉检查；未将其称为人工连续游玩。

结构化结果与截图位于 `tests/artifacts/teamplay-report.json`、`runtime.json`、`rules-offline.json`、`interactions-offline.json`、`team-visual.json` 及 `team-*.png`（生成文件不入库）。

旧 `browser-experience.cjs`、`browser-houses-novice.cjs` 包含此前单人追球的飞贼、固定接应和慢速追踪回传预期，不作为本轮球队玩法验收。
