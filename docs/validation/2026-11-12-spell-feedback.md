# 咒语表现差异

按用户确认的表格实现五种攻击咒的独立命中动作、持续特效和音色；辅助咒加入护罩、牵引线、区域边界、解咒碎片、恢复光点及固定金色穹顶。卢娜保留银兔守护神，不恢复原形立现。

头顶状态与剩余时间使用可读文字，效果叠加时可显示多个状态；暂停时动画冻结，重开时移除特效并恢复姿态。资源随角色更换和重开释放。
