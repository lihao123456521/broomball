# 随球镜头、比赛技能与人物面容

## 可见行为

- 默认镜头保持约 31.46° 略俯视，以实际持球者为中心，双方控球均适用。传球、射门和自由球跟随球；小幅速度预判和位置平滑避免球权变化时生硬跳转。
- 附近接应位置决定视野宽度，远处队员不能把镜头拉离球。V 切持球者近景，Tab 临时看全场；800 像素窗口保留雷达，操控者离开主画面时提示 C 切到近球追球手。
- 正式比赛的技能根据球权与威胁选择目标：防守锁持球者，进攻清理逼抢或传球线拦截者，自由球压制球旁争抢者。范围仍从实际施法球员测量，没有目标不消耗冷却。训练保留瞄准。
- 护盾保护 36 米内的持球 / 接球队友，或自己；保护时间绑定实体模型，切人不会移给另一个球员。队友的盾能真正阻止抢断并反弹游走球；无盾同样碰撞会掉球、短暂昏迷。
- 首页角色选择与比赛技能选择分开：1 / 2 / 3 不会在比赛中替换角色，C 负责换人。回首页、重新开赛或重开仍使用所选出场角色。技能锁定环在进攻与防守时都同步位置。
- 首页提供全身与正面面容近景，12 名球员均用实际三维角色。比赛面部卡使用同一角色工厂，含上传的 Harry GLB；操控者与持球者相同则合并，小窗口优先持球者。面部每秒最多约 8 帧，暂停和菜单停止刷新。
- 七个上传 GLB 保留实际球场实例；81 段已有自然女性英语声音继续本地播放。

## 设计参考

Konami 官方说明 Duel 镜头会在近身拼抢时拉近、在空当时展开：[PES 镜头说明](https://www.konami.com/games/eu/es/topics/16014/)。球权为主锚点、传球中跟球和本作 31° 角度是针对扫帚比赛作出的实现选择。

防守切人与球权参考：[eFootball 官方防守与切人说明](https://www.konami.com/efootball/en/page/2022/season1_patch-notes_v1-0-0)。本作仍由用户操作移动与切人，不会因为镜头跟到对手而自动移动玩家。
