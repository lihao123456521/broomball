# 四学院与追球清晰度验收

日期：2026-11-09。入口：根目录 index.html。基线：031de47c31901ffd58f5fd92955b9681135a802e。

## 改动与原因

用户反馈的主要障碍是球速过快、转向生硬、球场干扰过多，以及难以持续找到球。本轮围绕这条操作链调整：

- 训练和标准赛玩家射门 39 → 24 m/s，传球 34 → 22 m/s；巡航 28 → 22、冲刺 48 → 36 m/s。标准赛 AI、飞贼和游走球同步放缓。挑战赛保留较快节奏。
- 键盘和鼠标输入先更新目标角，再以短时指数平滑转动镜头；倒计时中也响应转向。
- 鬼飞球半径 0.78 → 1.05，采用亮橙色和白色缝线；屏幕跟踪圈标注位置和距离，离屏后显示方向箭头，持球时隐藏找球标记。
- 移除漂浮颗粒、低空云团、空中围网和大型悬浮航标，保留场外城堡、湖泊、看台与地面边界。
- 取消开场仍禁止拾取的额外等待；标准赛接球半径 4.2 米并检测相对运动路径，开场按 W 即可飞近拾球。
- 加入格兰芬多、斯莱特林、拉文克劳、赫奇帕奇选择，以及对手学院选择。制服、围巾、队名、比分和结算同步；四院徽章旗帜位于场外看台，选择会持久化。
- T 支持向持球队友要球；距离超过 38 米时队友先靠近。持续显示 X 减速接球提示，玩家回传期限 4 秒。球仍需要实际飞到玩家身边，持续远离可导致落空并有反馈。

## 验证结果

使用本机 Chromium、Playwright 实际键盘事件与隔离场景测试。测试时钟先于导航安装，所有测试使用本地 file 入口并拦截外网请求。

| 检查 | 结果 |
| --- | --- |
| browser-smoke.cjs --file | 10 / 10 通过 |
| browser-experience.cjs --file | 13 / 13 通过 |
| browser-houses-novice.cjs --file | 14 / 14 通过 |
| visual-review.cjs | 多尺寸布局、真实开场取球与画面采样通过 |
| 浏览器未处理异常 / 外网请求 | 均为 0 |

基础与体验回归覆盖训练完整链、射门穿门计分、背向射门、敌方射门拦截、传球、咒语、体力、暂停、重开与自然比赛结束。自然标准赛在约 132.512 秒以 0–150 结束；这是结算链路验证，不代表胜率或难度平衡。

专项验证包括四院切换和服装颜色、刷新持久化、换巫师后保留学院、结算队名、开场 W 拿球、F 射门实际速度 24 m/s、键盘渐进转向、鼠标输入边界平滑、倒计时视角更新、屏内球标与离屏箭头、持球隐藏球标，以及四个 T 要球场景。

回传测量：近距离球以 22 m/s 实际飞行；玩家 W 远离并按 T，650 ms 后按 X，约 1.3 秒内接到。持续 W 远离时不会瞬间获得球，4 秒后显示传球落空。倒计时输入后 50 ms，yaw 从 0 平滑推进至约 -0.255，玩家位置保持 [0,10,38]。

## 旧版本对照

基线的四项专项检查均按预期失败，页面异常与外网请求为 0：

1. W 第一次经过球的位置时，开场拾取锁仍未结束，无法拿球。
2. 射门实际速度 39 m/s，超出新节奏目标。
3. 键盘转向直接达到固定转速，没有渐进过渡。
4. 主菜单没有四学院选项。

保留基线报告与最终报告，不用修改后的结果覆盖失败证据。

## 画面检查与范围

检查实际渲染的 1440×900、1280×720、1024×768、800×600 画面。菜单无横向溢出，小窗口可滚动，开始按钮可用；球位标记与当前目标可见。标准赛截图由菜单开始，通过真实 W 取球、转向和 F 射门生成。静态环境 1,724 个网格合并为 37 批次；训练视角记录 192 次绘制调用和 243,587 个三角形，仅作为渲染统计，不是帧率测试。

本轮验证是浏览器自动化、实际渲染截图和独立代码审查，没有把它称为原生窗口中的人工连续游玩。鼠标平滑测试直接调用 pointer-lock 事件使用的输入边界，未伪装成真实鼠标设备测试。Godot 版本未同步或重新验收；手机触控不在本轮范围。
