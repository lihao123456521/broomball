# 我方主视角、传球手感与比赛大厅

## 本轮结果

主镜头始终由当前我方操控者决定，对手拿球、球飞远或射门不再改变镜头归属。默认31.46°略俯视，水平朝向固定；只有C切人或接球自动换控会平滑转到另一位我方队员。合法传球范围内的接应队员参与缩放，保持我方居中；V为我方近景，Tab为按住临时全场。远处球用球位标记与雷达提示。800宽度的头像也固定我方，宽屏第二张脸明确标注队友或对方持球。

WASD按屏幕方向移动，鼠标只选择传射方向。S保留65%后退速度；按住B时采用逼抢方向和温和高度跟随，Space/Q可覆盖高度，S+B不再误降速。Shift冲刺、X急停。J短传/要球、K直塞、F按住蓄力松开射门、C切人、1/2/3选技能+R使用，帮助与HUD统一。增加可按住的B屏幕按钮，J/K文字和所有按钮可用状态随球权更新；系统组合键不再触发技能。训练默认同一战术视角，不再先教另一套转向方式。关闭菜单帮助后会恢复3D预览。

传球重新计算可达接球点。AI短传送到手前，直塞沿实际水平跑动方向，无跑动时参考进攻方向，同时考虑转弯和加速。球路出手后固定，取消人为侧弯；低弧线保持连续速度。操控玩家的回传按实际速度预测相遇位置，必要时提高该次球速，避免强制改变玩家运动。极端冲刺背离目标仍可能超出可达范围，可X减速或改变跑位接应。

取消传球初段的全局不可拦截延迟；发送者单独禁止回收。接收者与拦截者均在实际持球手附近按1.35米判定，接球用0.14秒收球过渡，球员不瞬移。训练传球也真实换控到接球队员，球不再凭空回到原球员。失接后球沿切线继续，不停在终点。

首页以学院、出场角色、模式、开始比赛组成紧凑大厅。1440/1280/800宽度均无需滚动便可操作默认设置。三维展示约半屏，面容/全身与旋转工具独立显示，中文角色名突出。装备库是可关闭的局部抽屉。七个GLB和已有81段自然女性英语继续实际使用。
