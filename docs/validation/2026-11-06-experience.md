# 浏览器版完整体验与地图升级验收

日期：2026-11-06。入口：根目录 `index.html`。

## 已实现

- 引导训练、标准赛、挑战赛；训练无计时和敌方干扰，五步按真实动作推进，包含实际射门得分和施法。
- 标准赛 180 秒，飞贼 110 秒出现，对手 130 秒后才可追逐和捕获；挑战赛 150 秒、78 秒释放、93 秒开放对手争夺。
- 38 米内、准星对准门环才提供有限瞄准辅助；固定出手方向，穿越球门平面才计分。背射不会转弯，玩家可在来球穿门前拦截敌方射门。
- 己方接应手与守门员、T 传球、敌我区分；自由球越界反弹，仍能拾取；拾取与接球提供短暂保护，避免同一帧立即丢球。
- 冲刺体力与恢复、X 优先制动、←/→ 转向、I/K 俯仰、Tab 无球时切换飞贼追踪；持球目标始终优先进攻球门。
- 中文反馈、结算统计、分模式本机最佳成绩；暂停/结算/训练完成可返回菜单，重新开赛重置比赛状态。
- 高地、城堡、湖泊、树林、连续看台、两端球门标牌和地面高度标记。装饰不侵入可飞行区域。
- Three.js 0.160.0 及 MIT 许可证保存在 `vendor/`，游戏无 CDN 依赖。

## 当前版本验证

在本机 Chromium 中运行，使用 Playwright 真实键盘事件以及隔离的边界场景。测试时钟在导航前安装。

```text
node tests/browser-smoke.cjs --file
node tests/browser-experience.cjs --file
node tests/visual-review.cjs
git diff --check
```

浏览器运行依赖可由 `PLAYWRIGHT_MODULE` 和 `BROWSER_EXECUTABLE` 指定。

### 基础行为：10 组通过

移动与松键制动、冲刺时急停、升降、失焦暂停和清键、施法和无目标不扣冷却、昏迷禁用拾取与捕获、准星近距离锁定与远距离追踪命中、暂停冻结计时、飞贼按最终总分结算、重开与舒适设置持久化。巡航实测 28，松键后速度归零，页面未处理异常为 0。

### 新体验：13 组通过

1. 三模式的独立参数与训练无计时。
2. 真实移动和升降才推进训练。
3. 不改训练标志，纯键盘完成拾球、射门得分、施法，随后从完成按钮进入标准赛。
4. 背向射门没有辅助，球沿出手方向离开球门。
5. 远距离无辅助；近距离真实穿门计 10 分。
6. 玩家拦截敌方射门后不同时计分；自己的射门不会在出手瞬间被自己接回。
7. 越界自由球回到可达区域并可拾取。
8. 飞贼释放时机及对手保护期同时约束追逐与捕获。
9. T 传到队友，攻击咒语不锁定友军。
10. 冲刺耗体力、静止恢复、耗尽限制速度、X 优先。
11. 键盘转向与无球时 Tab 切换目标；持球时保持进攻指引。
12. 暂停冻结新增状态；真实按钮重开及返回菜单。
13. 不修改比分/剩余时间/结束状态，实际游戏循环自然结束，并显示统计、保存纪录、再次开赛。

最终自然比赛在约 131.18 秒以 0–150 结束（玩家仅做少量飞行后等待）。该测试证明比赛可自然结算，不代表玩家胜率或难度平衡结论。

两套 `--file` 测试阻断全部 HTTP/HTTPS 请求；游戏完整运行，未发出网络请求，页面未处理异常为 0。

### 画面与布局

实际渲染检查了 1440×900、1280×720、1024×768、800×600；主菜单无横向溢出，较小窗口内容可滚动，开始按钮可操作，当前目标持续显示。修复了俯瞰时天空被远裁面裁成黑块，以及训练雷达显示非参与球员的问题。

静态环境中 1,732 个网格合并为 37 个批次，并保留投影/接收阴影属性。训练场截图时记录 213 次绘制调用、251,202 个三角形；该数据只是该视角的渲染统计，不是帧率基准。
