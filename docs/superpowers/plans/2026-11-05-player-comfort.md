# 玩家体验优化实施计划

**目标：** 浏览器版优先，让人物、飞行操作、咒语效果与反馈一致且容易理解；Godot 同步核心行为修正。

**架构：** 保留浏览器单 HTML 与现有 Godot 项目结构，不替换引擎和比赛规则。按浏览器实现、Godot 同步、独立验证三条边界推进。

## 设计决定

- 保留哈利缴械、赫敏昏迷、罗恩护盾的角色配置，以中文技能名、作用、剩余冷却明确呈现。
- WASD 按镜头平移；Space/E 上升，Q/Ctrl 下降；Shift 加速；X 快速制动；F/左键射门；R/右键施法。S 明确为后退。去掉比赛中误触的重力/碰撞调试开关。
- 降低基础速度与滚轮上限，松键快速停稳；失焦和暂停清空输入；可调鼠标灵敏度和减少镜头动态。
- 模型保持程序化与可替换节点：更自然的躯干、关节、靴子、头发、披风和扫帚细节；加入魔杖与施法出射点。进攻球门蓝色、防守球门金色。
- 缴械主要造成掉球和短暂受击，昏迷造成较长停止或冻结游走球，护盾持续四秒并在切换角色时保持。限制瞄准辅助角度并提供目标提示。
- 修正方向箭头、暂停时计时、重开和切换视角状态。

## 工作边界

1. 浏览器：`index.html`。实现模型、输入、技能、可用性界面和状态修复。
2. Godot：`broomball/scripts/*.gd` 及 `tests/smoke_test.gd`。同步速度、制动、键位、技能与暂停状态，修正模型/门环可辨识性。
3. 验证：添加浏览器行为回归脚本；检查正常启动、移动/停止、三种技能、切角、暂停/恢复、重开、引导箭头及桌面尺寸布局；实际渲染截图审核。

## 验证标准

- 浏览器运行无未处理异常；技能命中效果与文案一致；对无目标、冷却中、暂停状态的操作有合理反馈或拒绝。
- 实际键盘事件验证，覆盖输入清理与暂停后恢复；检查模型和界面无遮挡。
- Godot 有运行时则执行 smoke test；无运行时明确记录验证范围，不以静态检查代替运行通过。
- 独立审核实现是否满足以上设计，再审核代码问题，修复后复测。
